기능

저장하는 순간 자동으로 컴파일되어 오른쪽에 PDF가 바로 갱신됩니다. 한글 문서는 xelatex, 그 외는 pdflatex을 자동으로 골라 써요. 컴파일 에러를 클릭하면 소스의 해당 줄로 바로 이동하고, PDF를 더블클릭하면 소스 위치로 — 양방향 SyncTeX. 자주 쓰는 수식·구조·기호는 단축 툴바 버튼으로 커서에 바로 삽입하고 즐겨찾기로 모아둘 수 있습니다.
워드(.docx)·한글(.hwpx)을 워드처럼 바로 편집합니다. 글자색·표·그림·수식이 원본 그대로 보이고, 표·그림·수식은 오른쪽 클릭 메뉴로 편집해요(행·열 삽입/삭제, 셀 병합·분할, 그림 크기·정렬, 글꼴 39종, √x 수식 실시간 미리보기). 오른쪽 미리보기는 실제 Word 엔진으로 변환해 진짜 페이지 나눔 그대로 보이고, 문장을 더블클릭하면 편집기의 그 위치로 이동합니다. PowerPoint는 레이아웃·폰트 그대로 PDF로 미리봅니다.
엑셀을 브라우저에서 실제 엑셀처럼 열어 값만 바로 고칩니다 — 머리글(A·B·C)·행 번호·병합 셀·시트 탭·이름 상자·내용 표시줄까지 그대로예요. 값만 편집되고 수식·서식·차트는 건드리지 않아 원본이 100% 안전하게 보존됩니다. PDF로 변환할 때는 시트·인쇄 범위·가로세로 1페이지 맞춤을 지정할 수 있어 진짜 엑셀에서 인쇄하는 것과 똑같습니다.
IEEE·Elsevier·ACS·APS·Nature·Science·IET·Wiley·MDPI 등 주요 저널과 NeurIPS·CVPR·ACL·ICML 등 유명 학회 양식 30여 종을 내장했습니다. ‘출판사·학회 선택 → 세부 저널 선택’ 2단계로 고르면 이름이 자동 기입돼요. ACS·APS·ACM·IEEE·LNCS 등은 바로 컴파일되고, 공식 클래스가 필요한 곳은 어디서 무엇을 받는지 단계별 팝업으로 친절히 안내합니다.
Beamer 발표 슬라이드 5종 테마(Madrid·Metropolis·Berlin·Singapore·CambridgeUS)와 일반 보고서·서류 골격을 클릭 한 번에 만들어 바로 작성을 시작합니다. 모두 한글(kotex)을 지원해 한글 발표자료도 xelatex로 자동 처리돼요. 슬라이드도 저장하는 순간 오른쪽에서 PDF로 바로 확인합니다.
워드·한글·PowerPoint·엑셀을 버튼 하나로 실제 PDF로 내보냅니다. 각 프로그램의 진짜 엔진으로 변환해 서식이 그대로 유지돼요. 특히 엑셀은 시트 선택·인쇄 범위·가로세로 1페이지 맞춤까지 지정할 수 있어, 진짜 엑셀에서 인쇄하는 것과 똑같은 결과가 나옵니다.
설치된 Claude Code·Codex·Gemini CLI를 문서 옆 패널에서 바로 호출합니다. 내 AI 계정을 그대로 연결해 골라 쓰고(구독은 각자), ‘이 문단 다듬어줘’처럼 말로 시키면 열린 문서에 바로 작업해요. ※ Gemini는 2026-06-18 구글 정책 변경으로 계정 로그인이 중단돼, AI Studio API 키(무료 등급 제공)가 필요합니다. 수정 허용을 켜면 폴더 파일을 직접 고치고, 대화 기억·실시간 토큰 표시·타임아웃 없음. 글쓰기·코드·번역을 한 창에서 끝냅니다.
모든 작업이 내 컴퓨터에서만 돌아갑니다. 문서를 클라우드에 업로드하지 않고 외부 서버로 보내지 않아요. 미공개 논문·연구 데이터·내부 문서도 안심하고 다룰 수 있습니다. 인터넷 연결이나 구독 없이도 편집·미리보기가 되고, 파일은 언제나 내 폴더 안에 그대로 있습니다.
